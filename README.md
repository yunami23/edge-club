# EDGE CLUB / 胆小鬼俱乐部

一款真正的**双设备在线双人对战**网页小游戏。网页 + 服务端代码全部包含在这个项目里，没有需要申请的 API key，也不需要数据库或第三方 Node 依赖。适用于 PC 浏览器和手机浏览器。

## 玩法

- 两人各自输入昵称；一人创建房间，把六位房间码或邀请链接发送给另一人。
- 房主开局。比赛共 **5 关**，两名玩家每关从悬崖起点重新出发。
- 每关的**安全距离由服务端随机确定为 5–9 格**。前四格必然安全，5–9 格后的风险递增；位置并不告诉你安全终点。
- 双方同时暗中选择「前进1步 / 前进2步 / 前进3步 / 收手保分」，等待双方选择完毕才公布。
- 前进成功后，本关累计分数等于 `安全前进的格数 × 10`；选择收手保分后才加到总分。一旦超出本关安全距离，你将坠崖，**本关累计分数归零**，但之前关卡的总分保留。
- 收手或坠崖的玩家本关不再操作；仍在悬崖上的玩家可以继续推进。两人都结束后揭晓真实安全距离，并自动进入下一关。
- 五关结束后，**总分更高者获胜**；同分判平局。两名玩家均同意后可立即重赛。

## 本地运行（需要 Node.js 20 或更高版本）

在终端进入项目文件夹，执行：

```bash
npm start
```

然后访问 `http://localhost:3000`。本地可以打开两个浏览器标签页测试；但要让不同地方的朋友通过互联网一起玩，需要把**整套项目**（不只是 `index.html`）部署到公开服务器。

运行自动化测试：

```bash
npm test
```

## 最省事的发布方式：Render

1. 将这个文件夹的所有文件上传到**一个 GitHub 代码仓库的根目录**（包含 `render.yaml`、`server.js`、`package.json` 和整个 `public` 文件夹）。
2. 登录 [Render](https://dashboard.render.com/) → **New** → **Blueprint** → 连接刚才的 GitHub 仓库，按界面提示部署。根目录的 `render.yaml` 已配置 Node 服务、启动命令、健康检查及 Free 实例。
3. 部署成功后，使用 Render 提供的公开 `https://...onrender.com` 地址打开网站，一人创建房间，另一人直接打开邀请链接。网页会自动用 `wss://` 建立实时连接。

也可以在 Render 上手动创建 **Web Service**，运行时选择 Node，启动命令填 `npm start`，部署健康检查路径 `/health`。

**注意：** 不要选择纯静态网站托管（如 GitHub Pages），它无法运行这个游戏的 WebSocket 服务器。

## 重要限制

- **我提供的是可部署的完整网站源码，并非已经上线的公网网站。** 在你自己的托管账号完成部署前，不会有一个能发给异地朋友的正式网址。
- 房间和比赛分数当前保存在运行进程内存中。**服务器重启、更新或休眠后，旧房间会消失**。普通小游戏试玩完全够用，但不适合需要长期保存记录的正式线上服务。
- Render Free 可能在空闲后休眠，首次进入时会有启动延迟；也可能按平台政策重启实例。上线长期稳定运营时，应添加持久化存储和收费实例。
- 当前设计为单实例运行。如果需要扩容成多个服务实例，应引入 Redis 等共享房间状态机制。
- 邀请链接仅包含随机房间码，不是密码保护。不要在昵称里填写个人隐私。
